# SRC garage — ระบบใบงานร้านแต่งรถ

เว็บใช้งานจริง: https://bigboybigzero.github.io/src-garage/ (ต้องล็อกอินด้วยบัญชีของร้าน)

บันทึกลูกค้า รถ และใบงานแต่ละครั้งที่รถเข้าร้าน · ค้นด้วยเลขทะเบียนแล้วเห็นประวัติทุกครั้ง ·
ติดตามงานค้างในร้าน รถที่เสร็จรอลูกค้ามารับ และยอดค้างชำระ

## หน้าจอ
ค้นทะเบียน · งานค้าง · รถที่เสร็จแล้ว · รับรถเข้า · ข้อมูลลูกค้า · รถ · รายการงาน · สำรองข้อมูล

## โครงสร้างไฟล์
    index.html                    ← ไฟล์ที่ GitHub Pages เสิร์ฟ (สร้างจาก build.sh ห้ามแก้ตรง ๆ)
    src/team-app.html             ← ตัวแอปทั้งหมด แก้ที่นี่
    src/_supabase-adapter.html    ← ชั้นเชื่อมฐานข้อมูล + หน้าล็อกอิน
    src/_demo-stub.html           ← ชั้นจำลองฐานข้อมูลไว้ทำหน้าสาธิต (เก็บข้อมูลในเบราว์เซอร์)
    src/supabase-setup.sql        ← SQL ตั้งตารางและสิทธิ์ ใช้ตอนตั้งโปรเจกต์ใหม่
    docs/                         ← ขอบเขตงาน ผังข้อมูล และเกณฑ์รับงาน

## แก้แล้ว deploy
    ./build.sh
    git add -A && git commit -m "อธิบายสิ่งที่แก้" && git push
GitHub Pages จะอัปเดตเองใน 1–2 นาที

## ข้อมูลและความปลอดภัย
ข้อมูลเก็บที่ Supabase (Postgres) ไม่ได้เก็บในเบราว์เซอร์ · เปิด Row Level Security ทุกตาราง
คนที่ไม่ล็อกอินอ่านและเขียนข้อมูลไม่ได้ · คีย์ที่ฝังใน index.html เป็น publishable key ที่ออกแบบมาให้เปิดเผยได้
ห้ามใส่ service_role key หรือรหัสผ่านใด ๆ ลงในรีโปนี้
