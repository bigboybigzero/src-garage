# SRC garage — ระบบบันทึกลูกค้าที่เข้ามาแต่งรถ

## ธุรกิจ
ร้านแต่งรถยนต์ รับงานประมาณ 6–15 คัน/วัน เจ้าของร้านและธุรการหน้าร้าน 1 คนเป็นคนกรอกข้อมูล
ตอนนี้ข้อมูลอยู่ในแชท LINE กระจัดกระจาย ทำให้ (1) หาประวัติรถลูกค้าเก่าไม่เจอ (2) ไม่รู้ว่างานค้างในร้านกี่คัน (3) ตามลูกค้ากลับมาไม่ได้

## เป้าหมายคาบนี้
ค้นด้วยเลขทะเบียนแล้วเห็นประวัติการเข้าร้าน "ทุกครั้ง" ของรถคันนั้น และดูงานค้างในร้านได้

## ขอบเขต
มี: ลูกค้า · รถ (ทะเบียน) · ใบงานต่อครั้งที่รถเข้าร้าน · รายการงาน+ราคา (เลือกจากดรอปดาวน์ทะเบียนรายการงาน หรือพิมพ์เอง) · สถานะ 4 ขั้น (รับรถ → กำลังทำ → ทำเสร็จ รอลูกค้ามารับ → ลูกค้ารับรถแล้ว) · มัดจำและยอดค้าง · ค้นด้วยทะเบียน
มีแล้ว: ฐานข้อมูลกลาง ทีมเปิดลิงก์เดียวกัน เห็นข้อมูลชุดเดียวกันแบบเรียลไทม์ แก้ไขลูกค้า/รถ/ใบงานได้
ไม่มีในคาบนี้: รับชำระหลายงวด · VAT/ใบกำกับ · สต๊อกอะไหล่ · รูปถ่ายรถ · แจ้งเตือน LINE · สิทธิ์ผู้ใช้แยกตามบทบาท (ดู BACKLOG.md)

## กฎข้อมูล
- ทะเบียนคือกุญแจค้นหา เก็บ `plate` แบบตัดช่องว่างและทำเป็นตัวพิมพ์ใหญ่ ค้นแบบไม่สนช่องว่าง/ตัวเล็กใหญ่ ทะเบียนซ้ำ = รถคันเดิม ไม่สร้างใหม่
- รถ 1 คันมีใบงานได้หลายครั้ง ใบงาน 1 ใบผูกรถ 1 คันเสมอ ลบลูกค้า/รถที่มีใบงานไม่ได้
- id ไม่เปลี่ยนตามชื่อหรือทะเบียน แก้ทะเบียนแล้วประวัติเดิมต้องยังตามมาด้วย
- เงินเก็บเป็นจำนวนเต็มสตางค์ ราคาที่บันทึกในใบงานเป็น snapshot ไม่เปลี่ยนย้อนหลัง
- ยอดรวม = ผลรวมรายการงานในใบนั้น · ยอดรับเงินสะสม (เริ่มจากมัดจำ) ต้อง 0 ≤ รับแล้ว ≤ ยอดรวม · ยอดค้าง = ยอดรวม − รับแล้ว · "จ่ายครบ" = ยอดค้าง 0
- รับเงินเพิ่มทีหลัง = บวกเข้ายอดสะสม รับบางส่วนได้ ห้ามเกินยอดค้าง · แก้ยอดสะสมโดยตรงได้เมื่อคีย์ผิด
- สถานะเดินหน้าเท่านั้น: รับรถ → กำลังทำ → ทำเสร็จ รอลูกค้ามารับ → ลูกค้ารับรถแล้ว กดซ้ำสถานะเดิมต้องไม่เกิดผลซ้ำ
- "งานค้าง" = ใบงานสถานะ รับรถ + กำลังทำ · "รถที่เสร็จแล้ว" แยก 3 กลุ่ม: รอลูกค้ามารับ / รับไปแล้วยังค้างชำระ / รับแล้วจ่ายครบ
- เก็บวันที่เป็น YYYY-MM-DD เสมอ แต่แสดงผลเป็นไทยเต็มรูปแบบ เช่น "วันอาทิตย์ 6 กันยายน 2026" (ปี ค.ศ. ตามที่เจ้าของร้านเลือก)
- ใช้ข้อมูลสมมติเท่านั้น ห้ามใส่ชื่อ/เบอร์/ทะเบียนของลูกค้าจริงหรือรหัสผ่านลงไฟล์
